*파트너스 활동을 통해 일정액의 수수료를 제공받을 수 있음

🏭 2026년 9월 25일 21:49에 시작해 26일 21:49에 끝나는 챌린지의 중간 기록입니다. 이 글을 쓰는 지금(26일 오전 10시 반) 기준으로 웹게임 87개가 나왔고, 수익은 아직 0원입니다.

무리한 주문으로 시작해보다.

요즘 이게 유행인지 Claude Code에게 이렇게 말했습니다.

“지금부터 24시간 줄 테니까 1천만 원을 벌어 와. 예산은 10만 원.”

첫 답은 “현실적으로 불가능합니다”였습니다. 계좌도 없고, 계약도 할 수 없고, 제휴 수수료가 3% 안팎이라면 1천만 원을 벌려면 24시간 안에 매출 3억 원이 넘게 필요하다는 계산이었죠. 맞는 말입니다.

그래서 제가 가진 것을 전부 내놓았습니다.

  • 쿠팡 파트너스 계정
  • 도메인 4개 (jungjoongi.com은 애드센스 승인됨)
  • Claude Code 계정
  • 개인사업자와 통신판매업 신고
  • 예산 10만 원

처음에는 디지털 템플릿 키트를 팔자는 안이 나왔는데, 저는 별로여서 “매력 없다”고 피드백했습니다. 그리고 정한 컨셉은… “AI가 24시간 동안 웹게임을 몇 개나 만들 수 있을까?”

수익은 광고(애드센스)와 쿠팡 파트너스로만 냅니다. 1천만 원은 사실상 표어고, 진짜 실험은 “AI 직원들로 공장을 돌리면 어디까지 되나”입니다.

공장 구조: AI 직원 5명

Claude Code 세션 5개를 tmux에 띄워 역할을 나눴습니다.

역할 하는 일
총괄 게임 기획, 지시, 결과 검수, 배포, 현황판 관리
빌더 공용 틀(헤더·결과 화면·공유·광고 자리), 로비, 인프라, 그리고 게임
게임 개발자 A 주로 액션·물리 게임
게임 개발자 B 주로 퍼즐 (생성기와 풀이기가 필요한 것)
게임 개발자 C 주로 퀴즈 (출처 검증이 필요한 것)

흐름은 심플하게 구성했어요.

  1. 총괄이 게임 하나를 한 문단으로 기획해 개발자에게 보냅니다.
  2. 개발자는 자기 폴더에서만 만들고, 로컬에서 테스트하고, 스크린샷을 직접 열어 확인한 뒤 보고합니다. 배포는 하지 않습니다.
  3. 총괄이 보고서와 스크린샷을 검수하고, 괜찮으면 배포하고, 곧바로 다음 게임을 맡깁니다.

사람인 제가 한 일은 방향을 정하고, 도메인 DNS 같은 계정 작업을 하고, 가끔 스크린샷 보고 “이거 이상한데?” 하는 정도였습니다.

숫자로 보는 공장 (26일 오전 10시 반 기준)

  • 출시한 게임: 87개
  • 종류: 액션 25 · 퍼즐 26 · 퀴즈 24 · 테스트 12
  • 한 게임 제작 시간: 평균 약 20분, 가장 빠른 건 5분(#07 1부터 50까지), 가장 오래 걸린 건 42분(#43 막차 러너)
  • 제작 시간 합계: 약 28시간 (여러 명이 동시에 만들어서 실제 경과 시간보다 깁니다)
  • 쓴 예산: 0원 (Vercel 무료 플랜, 이미 가진 도메인)
  • 수익: 0원
